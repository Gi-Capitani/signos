# 🔮 Projeto Signos do Zodíaco

Este é um projeto desenvolvido para a disciplina de **Programação Web**, que determina o signo do zodíaco de um usuário com base na sua data de nascimento. O sistema é construído em PHP e utiliza um arquivo XML para armazenar os dados de cada signo.

## ✨ Funcionalidades

- Formulário com Bootstrap para o usuário inserir sua data de nascimento.
- Verificação e comparação da data com as faixas de cada signo.
- Exibição do nome do signo, descrição personalizada e imagem de fundo temática.
- Layout responsivo, elegante e com cores harmoniosas.
- Rodapé fixo com direitos autorais.
- Organização em arquivos separados (`index.php`, `show_zodiac_sign.php`, `layouts/`, etc).

## 🧠 Tecnologias Utilizadas

- **PHP**: para processar o formulário e lógica de verificação.
- **XML**: como banco de dados local com as informações dos signos.
- **HTML5** & **CSS3**: estrutura e estilo da aplicação.
- **Bootstrap 5**: para estilização rápida e responsiva.
- **JavaScript** (pasta reservada): para melhorias futuras.
